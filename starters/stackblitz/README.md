# StackBlitz starter

A minimal Rspack project that uses the published `rspack-plugin-svg-sprite` package from npm.

[Open in StackBlitz](https://stackblitz.com/github/yichenzhu1337/rspack-plugin-svg-sprite/tree/main/starters/stackblitz)

This folder is deliberately not a workspace member: it installs the released package, so a reproduction here shows what users get. Run `npm install && npm run dev` to use it locally.
