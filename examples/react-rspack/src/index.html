Every flag in the world. One SVG sprite.

rspack-plugin-svg-sprite combines your .svg files into one sprite at build time. Each import gives you { id, viewBox, url } for <use>. A drop-in replacement for svg-sprite-loader on Rspack, Rsbuild and webpack 5.

npm i -D rspack-plugin-svg-sprite

How it works

This is the real config of this page: one rule for the flags, one for the UI icons.

// rspack.config.js
const {
  SvgSpritePlugin,
} = require('rspack-plugin-svg-sprite');

const sprite = {
  extract: true,
  spriteFilename: 'sprite.svg',
  esModule: false,
};

module.exports = {
  module: {
    rules: [
      {
        test: /\.svg$/,
        include: flagsDir,
        // = country-flag-icons/3x2
        type: 'javascript/auto',
        loader: 'rspack-plugin-svg-sprite/loader',
        options: {
          ...sprite,
          symbolId: 'flag-[name]',
        },
      },
      // a second rule, with symbolId 'icon-[name]',
      // handles the UI icons: same sprite.svg
    ],
  },
  plugins: [new SvgSpritePlugin()],
};

Extract mode, as on this page. Inline mode needs no plugin: see Modes.
