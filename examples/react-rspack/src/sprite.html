Inside sprite.svg

This demo imports <%= inputCount %> SVG files. At build time the plugin merges them into one file, sprite.svg. Opened on its own the file looks blank: a sprite only defines <symbol> elements, and a symbol is drawn where a <use href="sprite.svg#id"> points at it. Below, every symbol is drawn from that one file.

  1. Input <%= inputCount %> SVG files <%= flagCount %> flags + <%= iconCount %> UI icons · <%= inputSize %>
  2. Build rspack-plugin-svg-sprite loader + plugin, extract mode
  3. Output 1 file, … symbols · 1 request
